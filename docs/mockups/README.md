# Cockpit deck — design mockups

Standalone, throwaway HTML explorations of the front-end cockpit control deck.
They are **experiments**, not production code: open any file directly in a
browser (no build step). `surfer.svg` is the brand mark they mask.

Kept here so the explorations are not lost; safe to delete once the design is
settled.

| File              | Direction                          |
| ----------------- | ---------------------------------- |
| `1-coastal.html`  | Coastal Daybreak — light           |
| `2-citrus.html`   | Citrus Pop — light / warm          |
| `3-dusk.html`     | Dusk Lineup — refined dark ocean   |

The shipped deck draws from **Coastal Daybreak** (light) and **Dusk Lineup**
(dark), selectable via a light/dark toggle.
