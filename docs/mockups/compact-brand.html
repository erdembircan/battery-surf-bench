Compact bar — project name

Five ways to surface Battery Surf Bench inside the compact top pill. No logo — wordmark only, set in Anton (the deck title face) so it reads as the same brand. Each row is the real compact bar at full width; the last two repeat in the dusk (dark) palette. Pick a direction and I'll wire it into the SCSS + view.

1 · Left lockup + divider

Wordmark anchored far left on one line, a hairline divider separating it from the live status. Cleanest read, but eats horizontal room — fine on wide screens, tight when readouts wrap.
